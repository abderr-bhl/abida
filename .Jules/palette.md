# UI & UX Patterns

- **Top Pick Badge**: Used in buyer's guides to highlight the \#1 recommended product. Style: Orange (\#FF9900) background with dark text (\#111827) for accessibility.
- **Amazon Buttons**: Use \#FF9900 background, dark text for contrast, and include an external link icon. ARIA label should indicate it opens in a new tab.
- **Admin Dashboard**: Protected by Bearer token authentication on the API level.

# Accessibility

- **Contrast**: Avoid white text on \#FF9900 (ratio ~2.3:1). Use dark gray or black text instead (ratio ~7:1) to meet WCAG AA standards.
